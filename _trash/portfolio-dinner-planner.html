OVERVIEW
프로젝트 개요
"뭐먹을래?"는 모임에서 식당을 정할 때 발생하는 의견 충돌을 해결하기 위해 만든 실시간 투표 플랫폼입니다.
네이버/카카오 지도 링크만 붙여넣으면 자동으로 식당 정보를 파싱하고, 참여자 모두가 투표해서 민주적으로 장소를 결정합니다.
😫

Problem

  • 단톡방에서 끝나지 않는 식당 논쟁
  • "아무데나"라고 하면서 거절하는 친구들
  • 매번 같은 사람이 결정해야 하는 부담
  • 식당 정보를 하나하나 공유하기 번거로움
💡

Solution

  • 링크 공유 한 번으로 투표방 참여
  • 네이버/카카오 지도 링크로 후보 등록
  • 실시간 투표로 공정한 의사결정
  • 지도 뷰로 위치 한눈에 파악
HOW IT WORKS
누구나 쉽고 빠르게, 3단계

후보가 등록돼요.

3

투표 및 결정

실시간으로 투표하고
가장 인기 있는 곳을
확정해요!

FEATURES
주요 기능
🔗

링크 자동 파싱

네이버 지도, 카카오맵 링크를 붙여넣으면 식당명, 카테고리, 위치, 대표 이미지를 자동 추출합니다.

🗳️

실시간 투표

참여자 모두가 좋아요/싫어요로 투표하면 실시간으로 순위가 업데이트됩니다.

🗺️

지도 뷰

후보 식당들의 위치를 지도 위에 한눈에 표시하여 접근성을 직관적으로 파악합니다.

🎲

사다리 타기

투표로 결정이 안 될 때, 사다리 타기 기능으로 랜덤하게 선택할 수 있습니다.

👥

링크 공유 초대

별도 가입 없이 공유 링크만으로 투표방에 참여할 수 있습니다.

📊

관리자 대시보드

ABOUT THIS PROJECT
이 프로젝트는 실제 친구 모임에서 식당을 정할 때 겪는 불편함을 해결하기 위해 시작했습니다. "어디서 먹을까?"라는 단순한 질문에서 출발해, 누구나 쉽게 사용할 수 있는 투표 기반 의사결정 도구를 만들었습니다. 별도 가입 없이 링크만 공유하면 바로 참여할 수 있어, 실제 모임에서 활발하게 사용되고 있습니다.
