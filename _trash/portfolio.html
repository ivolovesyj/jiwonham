PROJECT 01  —  지원함 (JiwonBox)

jiwonham.vercel.app
OVERVIEW

취업 준비 중 여러 사이트에 흩어진 채용공고를 일일이 찾아다니던 불편함에서 출발. 크롤러로 공고를 자동 수집하고, 지원 현황 추적과 AI 자기소개서 작성까지 하나의 플랫폼에서 처리합니다.

① 지원 관리

상태별 탭 분류 (예정·보류·완료·합격), 회사·공고명 검색

② 채용공고 탐색

AI 선호점수, 카드·리스트 뷰, 지원안함·보류·지원예정 원클릭

③ AI 자기소개서

경험 소재 정리 후 공고별 자소서 AI 자동 작성

🤖 자동 크롤링

GitHub Actions로 매일 새벽 3시 지그재그 채용공고 자동 수집 → Supabase 저장

🔍 고급 필터링

직무(26개 대분류)·지역·기업유형·학력·경력 다차원 필터, AI 선호점수 정렬

📋 지원 현황 관리

지원 예정→완료→면접→합격 상태 추적, 드래그 앤 드롭 핀 고정, 메모·체크리스트

✍️ AI 자기소개서

OpenAI / Gemini API로 회사·직무 맞춤 자소서 초안 자동 생성

🎮 데모 모드

비로그인 상태에서도 localStorage 기반으로 모든 기능 체험 가능

➕ 외부 공고 추가

크롤링 외 다른 사이트 공고도 수동 등록해 통합 관리

PROJECT 02  —  뭐먹을래?

dinner-planner-nine.vercel.app
OVERVIEW

"오늘 뭐 먹지?" 고민을 함께 해결하는 실시간 그룹 투표 앱. 방장이 링크를 공유하면 친구들이 식당 후보를 올리고 좋아요/싫어요로 투표, 사다리 타기로 최종 결정. 설치 없이 링크 하나로 바로 사용 가능한 것이 핵심입니다.

랜딩 페이지

"이번 모임은 어디서?" — 투표방 만들기 원클릭, STEP 1·2·3 안내

투표방 내부

네이버/카카오 링크 붙여넣기 → 식당 자동 등록, 친구 초대 URL 공유

🗳️ 실시간 투표

좋아요/싫어요 투표 점수 실시간 반영, 안정적 정렬로 목록 순서 유지

🗺️ 지도 뷰

네이버맵·카카오맵 링크 붙여넣으면 지도 마커 자동 표시

🎲 사다리 타기

투표 상위 후보로 사다리 게임 진행, 최종 메뉴 재미있게 결정

👤 로그인 불필요

📱 모바일 최적화

모바일 우선 반응형 설계, 스마트폰에서 편리하게 사용

🛡️ 어드민 대시보드
