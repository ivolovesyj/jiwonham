OVERVIEW
프로젝트 개요
"지원함"은 취준생이 여러 채용 플랫폼을 매일 확인하는 번거로움을 해결하기 위해 만든 올인원 채용공고 관리 서비스입니다.
잡코리아, 원티드, 지행 3개 플랫폼의 채용공고를 자동 크롤링하고, 사용자 설문 기반 AI 필터링으로 맞춤 추천을 제공합니다.
😫

Problem

  • 여러 채용 사이트를 매일 번갈아 확인
  • 내 조건에 맞는 공고를 일일이 필터링
  • 지원 현황을 엑셀로 따로 관리
  • 마감일을 놓쳐 지원 기회를 놓침
💡

Solution

  • 3개 플랫폼 공고를 자동 수집 & 통합
  • AI 선호점수로 맞춤 공고 추천
  • 지원 상태별 이력 관리 대시보드
  • D-day 알림과 마감일 자동 추적

FEATURES
주요 기능
🔍

멀티 플랫폼 크롤링

잡코리아, 원티드, 지행 3개 채용 플랫폼의 공고를 매일 자동 수집하고 중복을 제거합니다.

🤖

AI 선호점수 추천

사용자 설문 기반으로 각 공고에 선호점수를 부여하고, 좋아요/싫어요 피드백으로 정확도를 개선합니다.

📋

지원 이력 관리

지원 예정, 지원 완료, 서류 합격, 면접 중 등 상태별로 관리하고 D-day를 추적합니다.

✍️

자기소개서 작성

경험 소재를 정리하고, 공고별 맞춤 자기소개서를 작성할 수 있습니다.

📱

카카오톡 일일 알림

매일 아침 8시에 맞춤 채용공고를 카카오톡 웹훅으로 자동 발송합니다.

🔄

카드 / 리스트 뷰

채용공고를 카드형과 리스트형 두 가지 뷰로 전환하며 비교할 수 있습니다.

ABOUT THIS PROJECT
취업 준비 과정에서 직접 겪은 불편함을 기술로 해결하고자 시작한 프로젝트입니다. 매일 여러 채용 사이트를 일일이 확인하는 대신, 크롤러가 자동으로 수집하고 AI가 나에게 맞는 공고를 추천해줍니다. 설문 한 번이면 매일 아침 카카오톡으로 맞춤 채용공고를 받아볼 수 있어, 실제 취준 생활에서 활용하고 있는 서비스입니다.
